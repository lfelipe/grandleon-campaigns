# Steel and Cedar

A five-battle Grandleon campaign with distinct solo and local co-op setups.
Sir Rowan leads the solo route; Akari brings a second army in co-op. The maps
exercise the engine's objectives, reinforcements, scrolling and hidden castle
interior. English, Spanish and Brazilian Portuguese are included.

This is a feature and translation showcase. A separately designed, thoroughly
balanced demo campaign remains planned before Grandleon 1.0.

`project.json` is editable source, initially copied from Grandleon 0.5.
The 0.5.0 release package uses Grandleon's built-in artwork and audio.
